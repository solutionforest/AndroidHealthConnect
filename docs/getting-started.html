Getting started

After install from npmjs or GitHub Packages, wire availability → permissions → read.

1. Check availability

import {
  getHealthConnectAvailability,
  openHealthConnectApp,
} from '@solutionforest/android-health-connect';

const info = await getHealthConnectAvailability();
if (info.availability !== 'installed') {
  openHealthConnectApp(); // opens HC or Play Store
}

2. Request permissions

Prefer typed Permission.* constants over hand-typed strings. 

import {
  Permission,
  ensurePermissions,
} from '@solutionforest/android-health-connect';

const { granted, missing } = await ensurePermissions([
  Permission.ReadSteps,
  Permission.WriteSteps,
]);

3. Read records

import {
  readSteps,
  timeRangeToday,
} from '@solutionforest/android-health-connect';

const page = await readSteps({
  timeRangeFilter: timeRangeToday(),
});

4. Poll on resume (first value often 0)

Health Connect has no push observer. After the app resumes, the first aggregate/read is frequently empty until Samsung Health / Fitbit / etc. finish syncing. Use useForegroundPoll (or pollUntil). 

import {
  readSteps,
  timeRangeToday,
  useForegroundPoll,
} from '@solutionforest/android-health-connect';

const { value, loading, refresh } = useForegroundPoll(
  () => readSteps({ timeRangeFilter: timeRangeToday() }),
  {
    ready: (r) => (r.records?.length ?? 0) > 0,
    timeoutMs: 15_000,
  },
);

Expo

SDK 50+ — add the config plugin, then npx expo prebuild:

{
  "expo": {
    "plugins": [
      [
        "@solutionforest/android-health-connect",
        {
          "permissions": [
            "android.permission.health.READ_STEPS",
            "android.permission.health.WRITE_STEPS"
          ]
        }
      ]
    ]
  }
}

Bare React Native

  1. Declare the same health permissions in the host AndroidManifest.xml.
  2. Add the Health Connect rationale activity / intent-filters (see repo README).
  3. Match AGP / compileSdk to the package line you installed (0.3 vs 0.2).
