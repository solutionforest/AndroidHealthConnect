Record types

All 42 Health Connect record types can be read and written. Each has a typed read helper; you can also use readRecords(RecordType.*, options).

→Read and write any type#

any-type.ts
import {
  readRecords,
  writeRecords,
  getFeatureStatus,
  timeRangeLastDays,
  RecordType,
} from '@solutionforest/android-health-connect';
import type { HydrationRecord } from '@solutionforest/android-health-connect';

const { records } = await readRecords<HydrationRecord>(RecordType.HYDRATION, {
  timeRangeFilter: timeRangeLastDays(7),
});

if ((await getFeatureStatus('skinTemperature')) === 'available') {
  const skin = await readRecords(RecordType.SKIN_TEMPERATURE, {
    timeRangeFilter: timeRangeLastDays(7),
  });
}

Field shapes for every type ship as TypeScript types (for example StepsRecord, HeartRateRecord). See the write guide for examples.
