Install

Same package name on both registries: @solutionforest/android-health-connect. Prefer npmjs unless your org already consumes GitHub Packages.

npmjs.org (primary)

No .npmrc required. Published via GitHub Actions Trusted Publishing (OIDC). 

# Default 0.3.x — connect-client 1.2.0-alpha06 (AGP 9.1+ / compileSdk 37)
yarn add @solutionforest/android-health-connect@0.3.14
# or
npm install @solutionforest/android-health-connect@0.3.14

# Maintenance 0.2.x — connect-client 1.1.0 stable (AGP 8.9.1+ / compileSdk 36)
yarn add @solutionforest/android-health-connect@release-0.2

Package page: npmjs.com/package/@solutionforest/android-health-connect

GitHub Packages (mirror)

Point the @solutionforest scope at npm.pkg.github.com. Use a classic PAT with read:packages (SSO-authorize for the solutionforest org if required). 

# .npmrc
@solutionforest:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=YOUR_GITHUB_PAT
yarn add @solutionforest/android-health-connect@0.3.14

Also available as a GitHub Release .tgz (with SPDX SBOM + attestations): Releases.

Requirements (0.3.x)

Requirement Value
React Native ≥0.84 (New Architecture / TurboModules)
Node.js ≥22.22
AGP / Gradle 9.1.0+ / 9.3.1+
compileSdk 37
Android OS API 29+ (Health Connect app on 9–13; built-in on 14+)
Platform Android only — no iOS implementation
