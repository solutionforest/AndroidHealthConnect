Install

Same package name on both registries: @solutionforest/android-health-connect. Use npmjs unless your org already consumes GitHub Packages.

01Pick a registry

Every release is published to npmjs.org by GitHub Actions through OIDC Trusted Publishing, then mirrored to GitHub Packages.

npmjs.org primary

No .npmrc needed.

terminal
yarn add @solutionforest/android-health-connect

GitHub Packages mirror

Classic PAT with read:packages.

.npmrc
@solutionforest:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=YOUR_GITHUB_PAT

SSO orgs: if your GitHub org enforces SAML SSO, authorize the PAT for solutionforest or installs from GitHub Packages return 403.

02Choose a version line

04Install the AI agent skill

The package includes skills.md, a skill file that tells coding agents how to use this library: which version line to pick, the hard constraints, and the availability → permissions → read order. Copy it from node_modules so it matches the version you installed.

terminal
mkdir -p .cursor/skills/android-health-connect
cp node_modules/@solutionforest/android-health-connect/skills.md \
  .cursor/skills/android-health-connect/SKILL.md
terminal
mkdir -p .claude/skills/android-health-connect
cp node_modules/@solutionforest/android-health-connect/skills.md \
  .claude/skills/android-health-connect/SKILL.md
terminal
mkdir -p .agents/skills/android-health-connect
cp node_modules/@solutionforest/android-health-connect/skills.md \
  .agents/skills/android-health-connect/SKILL.md

Commit the skill folder and re-copy it after upgrading. Prefer to let the agent do it? Use the copy-paste prompt, or read skills.md first.
